# Bhoomi Sharma — Portfolio Website

A professional PR & Communications portfolio site.

## How to put this live on GitHub Pages (free, takes 10 minutes)

### Step 1 — Create a GitHub account
Go to github.com → Sign up free → use your name as username (e.g. bhoomisharma)

### Step 2 — Create a new repository
- Click the green "New" button on your GitHub dashboard
- Repository name: **bhoomisharma.github.io** (EXACTLY this format — your username + .github.io)
- Set it to Public
- Click "Create repository"

### Step 3 — Upload your file
- Click "uploading an existing file" link on the new repo page
- Drag and drop the index.html file
- Scroll down, click "Commit changes"

### Step 4 — Your site is live!
Wait 2-3 minutes, then visit: **https://bhoomisharma.github.io**
That's your portfolio URL. Add it to your CV and LinkedIn.

## How to add your photo
In index.html, find the two sections that say "Add your photo here"
Replace the placeholder div with:
`<img src="photo.jpg" alt="Bhoomi Sharma" style="width:100%;height:100%;object-fit:cover;">`
Then upload your photo.jpg to GitHub alongside index.html.

## How to add portfolio PDFs
1. Upload each PDF to Google Drive
2. Right-click → Share → "Anyone with the link" → Copy link
3. In index.html, find the port-card for that piece
4. Replace href="#" with your Google Drive link

## How to update content
Just edit index.html directly on GitHub (click the file → pencil icon → edit → commit)
Changes go live within 1-2 minutes.
